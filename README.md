# ADAM Institute website

Static website for ADAM Institute of Management and Technology Private Limited.

## Pages

- `index.html` – Home
- `about.html` – About Us
- `programs.html` – Programs
- `facilities.html` – Facilities
- `innovation.html` – Innovation
- `collaborations.html` – Collaborations
- `contact.html` – Contact

All CSS and JavaScript are inside each HTML file. Images and the banner video are in `images/`. Fonts load from Google Fonts.

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Before launch

- Connect the enquiry forms (Contact, Innovation, Collaborations) to an email or form service. They currently show a "coming soon" message.
- Add the verified email, phone, address and office hours (Contact page and footer).
- Add a `privacy.html` Privacy Notice page.
- Replace stock photos with approved photos of the institute where available.
